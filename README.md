# 🛕 Tirupati Pilgrim Analytics Dashboard

## 📌 Project Overview

The  Tirupati Pilgrim Analytics Dashboard is an end-to-end data analytics project designed to analyze pilgrim-related data and provide meaningful insights into temple operations.

The project analyzes data related to:

- Pilgrim registrations
- Darshan bookings
- Waiting time
- Donations
- Prasadam orders
- Transportation
- Accommodation

The final insights are presented through an interactive Power BI dashboard.

---

## 🎯 Objectives

1. Analyze pilgrim demographics and visitor patterns.
2. Understand darshan booking and waiting-time trends.
3. Analyze donations, prasadam and accommodation revenue.
4. Support data-driven operational decision-making.
